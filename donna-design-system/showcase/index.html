donna design system · v1.0.0 · showcase

a closed grammar, forever.

six colors, three signals, two type families, one rust moment per screen. every surface in donna is composed from these primitives. no new values, ever. this page is the reference.

07 · the rule

when in doubt, ink on paper, sans-serif, no shadow.

the forbidden list
  • a new hex color anywhere in code
  • two rust elements on one screen
  • italic outside the three approved roles
  • serif at weight 700
  • drop shadow on a card at rest
  • pure #000 as text (use ink = #1E1A18)
  • underlines on links (use rust + bottom border)
  • gradients anywhere, ever
